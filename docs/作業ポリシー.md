# 作業ポリシー（Codex と共同作業）

- **対象**: `keyballBLE` リポジトリで Codex と共同作業を行う全タスクに適用。
- **事前共有**: 作業前に目的・触るファイル・懸念点・バックアップ位置を共有し、確認を取ってから着手する。
- **差分管理**: 作業中は適宜 `tree` や `git status` で状態を共有し、完了時には `git diff` を提示してレビューを受ける。
- **コミット/Push**: ユーザーの合図があるまで push は実施しない。コミットも事前確認のうえで実行する。
- **使用言語**: やり取りは原則すべて日本語で行う。
- **構成変更**: フォルダ構造やファイル配置を変える大きな変更は、必ず事前相談＋合意のうえで実施する。
- **バックアップ**: 構造が変わるような大きな変更を始める前に、対象フォルダをそっくりバックアップし、場所を共有する。
- **異常検知**: 想定外のファイル変更やビルドエラーを検知したら即座に報告し、指示を仰ぐ。
- **禁止事項**: 無断でクリーン/リセット/強制 push などの破壊的操作を行わない。
- **不明点の扱い**: 推測で進めず、わからないことは正直に伝えて相談する。
- **参照資料**: ZMK の公式ドキュメントや最新情報に基づいて対応し、過去の記事だけで判断しない。

必要に応じて内容を更新し、最新の合意事項をここに記載する。
