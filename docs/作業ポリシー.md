# KeyballBLE 作業ポリシー

更新日: 2026-09-03

## 対象と正本

- 公開リポジトリ `keyballBLE/` は設定の正本であり、通常の再現ビルドでは読み取り専用で扱う。
- 再現可能なZMK v3ビルドのmanifest、Docker資産、スクリプト、手順書は `/Users/shige/dev/keyboards/_local-build/` が正本である。
- workspace、Dockerイメージ、UF2は生成物であり、Gitへ追加しない。

## 作業上の約束

- 変更前に対象・目的・影響範囲・確認方法を共有する。
- 構成変更、workspace削除、Docker削除、出力削除は、対象と容量を確認してから明示承認を得る。
- `git reset --hard`、強制push、既存出力の削除、無断コミットは行わない。
- `00_west_init.sh` は既存workspace復旧用であり、初回workspace作成には使わない。初回作成はDocker内のWestで行う。
- PMW3610は通常用・検証用の両方に必要である。Raytacドングルの固定revisionを理由なく更新しない。
- 作業後は変更一覧と確認結果を共有し、コミットが必要なら内容を分けて提案する。実行は承認後だけにする。
